# Common Issues & Quirks

| You see | Likely cause | Fix |
| --- | --- | --- |
| No buttons after Start | First-visit microphone prompt, or volume too low | Reload once; turn volume up; iPhone silent switch off |
| "Could not hear our own chirps" | The phone can't hear itself | Volume up, nothing covering the speaker or mic, reload |
| "ERROR: No microphone access… https://" | Page not opened over https | Use the `https://….github.io/…` address |
| "Could not load cells/…" or "did not call registerCell()" | Wrong file name, or a typo in the cell file | Check the name and the code; the app uses a built-in cell meanwhile |
| Red dot, "Instructor not heard" | Instructor too quiet, too far, or its page went to the background | Louder speaker; keep the instructor page in front; don't let the laptop sleep |
| "Heard only 0–2 sync chirps" | Partner phone not synced, or beacon off, or too far apart | Check the partner's dot is green and its beacon is on; hold the phones a few cm apart |
| Clock test warns about the window edge | The clocks drifted more than about 20 ms apart | Re-sync and restart the test |
| Edit doesn't show on the phone | GitHub Pages still updating, or the phone kept the old copy | Wait 2 minutes, reload; check the Actions tab |
| My pushed changes were not displayed | Browser caching old version of website | Clear browser cache, or add &v=2 to the end of the address for a fresh copy |
| "Sync here" needs the clock set to "Follow instructor chirps". | Clock is not set to "Follow instructor chirps" for expert mode | Change setting for clock to "Follow instructor chirps" |
